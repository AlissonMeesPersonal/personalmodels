# Personal Brasil

Plataforma em desenvolvimento para encontrar profissionais de Educação Física. A versão inicial contém perfis fictícios para demonstração, sem cadastro, verificação de CREF ou pagamentos ativos.

## Executar

```bash
npm install
npm run dev
```

## Próximas etapas

- Contas e permissões para administrador, personal e cliente.
- Verificação manual do CREF antes da publicação de perfis.
- Assinaturas recorrentes e rodízio de posições patrocinadas.
